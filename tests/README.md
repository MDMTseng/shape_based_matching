# Tests & Benchmarks

## Quick Start

```bash
# Build all tests
cmake --build build --config Release

# Run regression (all 151 checks)
build/Release/test_regression.exe all

# Run specific section
build/Release/test_regression.exe 3        # ROI refinement only
build/Release/test_regression.exe 6 10     # speed benchmarks only
build/Release/test_regression.exe -h       # show help
```

## Thresholds (test_thresholds.csv)

Performance boundaries are defined in CSV format — editable without recompiling:

```csv
id,type,metric,op,threshold,description
3a_roi_ang_mean,check,roi_ang_mean,<,0.2,ROI angle mean (deg)
3a_roi_pos_mean,check,roi_pos_mean,<,0.1,ROI position mean (px)
6_speed_roi,warn,fhd10_roi_ms,<,32.0,FHD 10-obj ROI speed (ms)
```

- `type=check`: PASS/FAIL — test fails if threshold exceeded
- `type=warn`: advisory — warns but doesn't fail
- Comments start with `#`
- Original values tracked in comments when thresholds are relaxed

Custom thresholds: `test_regression all -c my_thresholds.csv`

## Adding New Tests

1. Create `tests/test_new.cpp`
2. Add to `CMakeLists.txt`:
   ```cmake
   add_executable(test_new line2Dup.cpp icp_refine.cpp roi_refine.cpp shape_matcher.cpp tests/test_new.cpp)
   target_link_libraries(test_new ${OpenCV_LIBS})
   ```
3. Use `OutputGuard` to suppress library output:
   ```cpp
   #include "test_utils.h"
   { OutputGuard guard; auto results = matcher.match(scene); }
   ```
4. For regression checks, add RECORD() calls and CSV thresholds

## Logging

Tests use `sbm_log.h` for library output control:

```cpp
// Enable debug logging for investigation
sbm::setLogLevel(sbm::LogLevel::Debug);
sbm::setLogTimestamp(true);
sbm::openLogFile("debug.log");

// Silence everything (production)
sbm::setLogLevel(sbm::LogLevel::Off);
```
